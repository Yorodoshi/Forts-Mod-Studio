# Forts Mod Studio 2.7.1

> **Выпуск выведен из рекомендуемых.** По просьбе владельца после отчёта VirusTotal 4/71 основным выпуском снова назначена 2.7.0. Версия 2.7.1 сохранена как предварительная для анализа. [Подробности возврата](rollback-to-v2.7.0.md).
>
> **Superseded as the primary release.** At the owner's request following a 4/71 VirusTotal report, 2.7.0 is the primary release again. 2.7.1 is retained as a prerelease for investigation.

## Русский

Обновление безопасности и прозрачности сборки.

- Импортированный проект больше не может назначить новую папку запуска DLL/EXE: используется найденная Steam-установка или явно выбранная локальная папка игры.
- Загрузка декодера изображений ограничена проверенной библиотекой игры; зависимости ищутся только рядом с ней и в System32. Вызовы привязаны к загруженному модулю.
- Исправлены проверки размеров изображений, защита выходных путей ресурсов и имён временных аудиофайлов.
- У анализатора Lua заданы полный путь, рабочая папка, одновременное чтение журналов и ограничение времени ожидания.
- Добавлены манифест `asInvoker`, сведения о сборке, SHA256 и сборка/аттестация происхождения EXE и ZIP на GitHub Actions.
- Добавлены документ безопасности, инструкция по проверке выпуска и шаблон обращения о возможном ложном срабатывании.

**Подпись и сканирование:** EXE пока не подписан сертификатом Authenticode. Отчёт 2/68, предоставленный пользователем, относится к 2.7.0. Для 2.7.1 пользователь предоставил отчёт VirusTotal 4/71; чистый результат не заявляется. Аттестация подтверждает происхождение сборки, а не антивирусный вердикт.

Сохраните проект и закройте старую FMS перед запуском. Если проект создан на другом компьютере, при необходимости выберите свою установку Forts в настройках проекта.

## English

Security and build-transparency update.

- Imported projects cannot approve a new native-library or executable directory. FMS uses a Steam-discovered or explicitly selected local Forts installation.
- Restricted decoder loading and dependency lookup, with calls bound to the verified module handle.
- Checked image dimensions, confined generated resource paths and safe audio-preview filenames.
- Explicit Lua-checker path/working directory, concurrent output reads and bounded process wait.
- Explicit `asInvoker` manifest, SHA256 checksums, build metadata and GitHub Actions build provenance for EXE/ZIP.
- Added security documentation, release-verification instructions and a possible-false-positive review template.

**Signing/scanning:** this binary is not Authenticode-signed. The user's 2/68 report applies to 2.7.0. The owner supplied a 4/71 VirusTotal report for 2.7.1; no clean result is claimed. Build provenance is not an antivirus verdict.

Save your project and close older FMS versions before updating. Projects from another computer may require selecting your own Forts installation.
