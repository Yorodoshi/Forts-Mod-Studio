## Русский

Первый выпуск Forts Mod Studio в этом репозитории.

- Переключение **Русский / English** в верхней панели; русский при первом запуске.
- Выбранный язык запоминается отдельно от проекта. Названия и описания проекта сохраняются в исходном виде.
- Переведены основные редакторы, сценарии, диалоги, полигон и показатели предпросмотра.
- Отрисовка использует плитки мира, подготовленные повороты снарядов и отдельные изображения неподвижных сооружений.
- Приложены исходники, инструкции на двух языках и скрипт сборки Windows.

**Запуск:** скачайте и распакуйте ZIP или скачайте отдельный EXE. Нужны Windows x64, .NET Framework 4.x и установленная Forts для игровых ресурсов. Перед обновлением сохраните проект и закройте прежнюю FMS.

Сборка выполнена без ошибок и предупреждений. Интерактивный прогон интерфейса и замер FPS этого выпуска не выполнялись.

## English

The first Forts Mod Studio release in this repository.

- Live **English / Русский** switching in the top toolbar, with Russian as the first-launch default.
- Interface language is remembered independently of projects and does not rewrite editable project content.
- Translated editors, scenarios, dialogs, range instructions and preview diagnostics.
- Retained world tiles, prepared projectile rotations and stationary-object sprites.
- Source code, bilingual documentation and a Windows build script.

**Run:** extract the ZIP or download the standalone EXE. Requires Windows x64, .NET Framework 4.x and an installed Forts copy for game resources. Save your project and close older FMS versions before updating.

The build completed without errors or warnings. This release has not undergone an interactive UI run or FPS measurement.
