# Forts Mod Studio 2.8.0

## Русский

Переменные, формулы и редактор сценариев.

- Типы **«Целочисленное»**, **«Дробное»**, **«Список»**. Старые числовые переменные сохраняют значения и открываются как дробные.
- Формулы начальных значений и числовых полей сценария: арифметика, тригонометрия, логарифмы, списки, численные производные и интегралы.
- Отдельная панель справа: все переменные, тип, область, формула, вычисленное начальное значение. Текущие значения из запущенного матча не считываются.
- Полный редактор с сохранением/отменой. Переименование обновляет ссылки; удаление используемой переменной показывает зависимости.
- Действие **«Редактировать переменную»**: задать, прибавить, умножить; заменить список, добавить/изменить/удалить элемент или очистить список.
- Проверки типов, индексов, циклических зависимостей и ограничений вычисления. Формулы экспортируются как дерево данных без исполнения введённого текста как Lua-кода.
- Встроенный гайд с поиском, примерами и полным справочником на русском и английском.

**Начало работы:** «Сценарии» → справа «Переменные» → «＋ Переменная». Пример дробного значения: `sqrt(81) * 2`; список: `range(1, 12)`; шаг изменения: `$counter + 1`.

[Гайд по методам и формулам](../formulas.md).

Перед обновлением сохраните отдельную копию проекта и закройте прежнюю FMS. Распакуйте ZIP и запустите **Forts Mod Studio 2.8.exe**. Новые типы и формулы требуют версии 2.8 или новее. Громкость аудиоблоков, параметры штатных осколков, интервалы циклов и дополнительное поле скорости сохраняют фиксированные числовые настройки.

Сборка выполнена локально штатным компилятором .NET Framework x64. Автоматические тесты и интерактивный прогон FMS/Forts не выполнялись. Приложены `SHA256SUMS.txt` и `build-info.json`. EXE не подписан Authenticode; результат VirusTotal для 2.8.0 не заявляется. Отчёты прежних версий к этому файлу не относятся.

## English

Typed variables, formulas and scenario editing.

- **Integer**, **floating-point** and numeric **list** values. Existing numeric variables retain their values and load as floating-point.
- Initial-value and scenario formulas: arithmetic, trigonometry, logarithms, lists, numeric derivatives and integrals.
- A dedicated right-hand pane lists all variables, types, scopes, formulas and computed initial values. It does not read live values from a running match.
- Save/cancel editing, reference-aware renaming and dependency-aware deletion.
- **Edit variable** actions assign/add/multiply numbers or replace/append/update/remove/clear lists.
- Type, index, dependency and work-limit checks. Exported formulas are data trees, not executable input text.
- A complete searchable offline guide in Russian and English.

**Start:** Scenarios → Variables on the right → ＋ Variable. Try `sqrt(81) * 2`, `range(1, 12)` or an action formula such as `$counter + 1`.

[Method and formula guide](../formulas.en.md).

Save a separate project copy and close the old FMS before updating. Extract the ZIP and run **Forts Mod Studio 2.8.exe**. New formulas/types require 2.8 or later. Audio volume, native-fragment settings, loop intervals and the secondary projectile-speed field retain fixed numeric settings.

Built locally with the Windows .NET Framework x64 compiler. Automated tests and interactive FMS/Forts runs were not performed. Checksums and build metadata are attached. The EXE is not Authenticode-signed; no VirusTotal result is claimed for 2.8.0. Reports for previous versions do not apply to this file.
