# Repository work

- Record every user-visible change in `CHANGELOG.md`.
- Put release notes in `docs/releases/` and attach ready-to-run builds, checksums and build information to GitHub Releases.
- Keep user-facing instructions available in Russian and English. Russian remains the default interface language.
- Preserve user project data when changing the interface language.
- Do not commit personal projects, imported images, credentials, installed game files or local autosaves.
- Treat antivirus detections as issues to investigate and report to the detecting vendor. Do not modify binaries merely to evade detection or present an unverified scan result as clean.
- Prefer published build provenance and honest signature/scan status over unsupported assurances.
